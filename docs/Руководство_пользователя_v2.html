Руководство пользователя — пульт управления мачтой (версия 2)

Прошивка: mast_control_v2
Дисплей: OLED 128×64, I2C (модуль 2,42″)
Давление: петля 4–20 mA (ИВЭ-50), измерение тока модулем INA219
Аудитория: оператор пульта — чтение экрана и типовые действия. Монтаж: Пины_Arduino_Nano_v2.md; логика джойстиков (как v1): Описание_системы_управления.html.

1. Назначение

Пульт предназначен для:

  • подъёма и спуска первой и второй секций мачты (два джойстика);
  • выдвижения и задвижения «пальцев» (третий джойстик);
  • пропорционального управления гидравлическим клапаном (мощность по отклонению ручки);
  • индикации давления в гидросистеме (шкала 0…250 bar);
  • установки рабочего нуля датчика давления кнопкой на панели.

Одновременно активна только одна ось. Остальные джойстики не управляют клапанами, пока первая не возвращена в нейтраль (раздел 4).

2. Меры безопасности

  1. Перед работой убедитесь, что аварийная кнопка «СТОП» (если установлена) разрешает питание пульта и МК.
  2. Нейтраль по безопасности — только когда разомкнут концевик на рукоятке. Положение ручки «по центру» без концевика не считается нейтралью.
  3. Кнопку нуль давления удерживайте намеренно: срабатывание после 3 с удержания.
  4. При надписях OPEN, SHORT, I2C FAILED не опирайтесь на цифры давления — устраните неисправность или обратитесь к обслуживающему персоналу.

После подачи питания на OLED кратковременно отображаются:

4. Управление джойстиками (кратко)

ЭлементНазначение
Концевик нейтралиРазомкнут → ось отключена. Замкнут → ось может работать.
Потенциометр (ручка)Сначала реле (направление), затем при большем отклонении — ШИМ пропорционального клапана.

Оси

ДжойстикФункцияРеле
1Секция мачты 1Подъём / спуск
2Секция мачты 2Подъём / спуск
3«Пальцы»Закрыть / открыть

Типовая последовательность:

  1. Нейтраль (концевик разомкнут).
  2. Нажать/отклонить рукоятку — ось активна (заполненный кружок на дисплее).
  3. Отклонить: вверх/закрыть (стрелка вверх) или вниз/открыть (стрелка вниз).
  4. Завершение — снова нейтраль.

Смена направления (вверх ↔ вниз) — только после полного возврата в нейтраль по концевику.

Подробности — в Описание системы управления (логика v1 = v2).

5. Главный экран (GUI)

Верх — давление или сообщение; низ — оси и ШИМ (нижняя часть почти всегда на экране).

┌────────────────────────────────────────┐
│        012 bar          │ 100          │  ← давление или ошибка
│                         │ ┃            │     шкала ШИМ справа
├─────────────────────────┤ ┃            │
│    ○      ○      ●↑     │ ┃▓▓          │  ← пальцы, мачта2, мачта1
└────────────────────────────────────────┘
                                    0

5.1. Индикация давления (норма)

  • Цифры 000…250 и подпись bar.
  • Шаг на дисплее — 2 bar (0, 2, 4, …).
  • Малые значения у нуля могут показываться как 000 (подавление дрожи).
  • По умолчанию: 4 mA ≈ 0 bar, 20 mA ≈ 250 bar; после нуля (§6) — от тока в момент tare.

Важно: ток ниже зафиксированного нуля на дисплее даёт 0 bar, не «минус». Сильное падение — см. OPEN (§7).

5.3. Шкала справа (ШИМ)

  • Сверху 100, снизу 0 — мощность пропорционального клапана активной оси (0…100 %).
  • Заполнение растёт после срабатывания направления реле.
  • Нет активной оси — шкала пустая.

6. Кнопка «нуль давления» (ZERO)

На панели: кнопка «нуль» / tare (на МК — D12, нажатие на GND).

Назначение: запомнить текущий ток в петле как 0 bar (в RAM; после перезагрузки снова опора 4 mA, пока не выполните tare).

  1. Установите режим/давление, которое должно читаться как 0 bar.
  2. Удерживайте кнопку не менее 3 с.
  3. На экране: TARE… → ZERO SET (~1,2 с).
  4. Отпустите кнопку — 000 bar при том же токе.
  5. Повторный tare — после отпускания и паузы.
СообщениеЗначение
TARE…Идёт удержание
ZERO SETНоль принят
TARE FAILУсловия не выполнены

TARE FAIL — нет I2C, OPEN/SHORT, ток вне ~3,6…19 mA.

7. Сообщения об ошибках

При ошибках цифры давления скрыты; нижняя полоса (оси, ШИМ) остаётся.

ЭкранДля оператора
PRESSURE SENSOR / OPENСлишком малый ток (обрыв, нет сигнала).
PRESSURE SENSOR / SHORTСлишком большой ток (перегруз, КЗ).
I2C / FAILEDНет обмена по I2C (проводка, питание модулей).

Прекратите опору на давление, проверьте ИВЭ-50 и модули, при необходимости — специалист. После восстановления — снова 000…250 bar.
