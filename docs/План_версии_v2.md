# План версии 2

## Разделение v1 / v2

| Часть прошивки | v1 | v2 |
|----------------|----|----|
| Джойстики, концевики, одна активная ось | эталон | **без изменений** (копия v1) |
| Реле D2–D7, ШИМ D11 | эталон | **без изменений** |
| INA219, пороги OC/SC, map давления (пока) | эталон | **без изменений** |
| Индикация | TM1637, 4 символа | **OLED U8g2** — другой вывод и будущий GUI |
| ИВЭ-50, нуль по кнопке | — | только v2 (давление + дисплей) |

Любая правка «железной» логики — сначала в **v1**, затем перенос в v2.

## Цели

1. **Не ломать** логику **v1** (джойстики, блокировка осей, реле, ШИМ D11).
2. **Дисплей:** OLED **SSD1309**, 2,42", 128×64 (I2C `0x3C` / `0x3D`).
3. **Давление:** INA219 в **разрыве** петли датчика на **ИВЭ-50** (без отдельного БП для имитации 4–20 mA).
4. **Нуль:** кнопка **D12** — удержание **3 с** (не короткий клик), затем `loop_zero_mA` = текущий ток; шкала **`loop_zero_mA…20 mA` → 0…250** (RAM). До удержания опора **4,0 mA**.
5. **GUI:** крупное давление, статусы `-OC-` / `I2c-`, активная ось, режим нуля.

## Proteus: SSD1309 vs SSD1306

| | Железо | Proteus |
|---|--------|---------|
| Чип | SSD1309 | Модели **SSD1306** |
| Разрешение | 128×64 | 128×64 |
| Шина | I2C (или SPI — по вашему модулю) | Те же линии SDA/SCL |

Для **симуляции** достаточно SSD1306: проверяются адрес, такт, уровни.  
Для **прошивки на модуле** — драйвер с инициализацией **SSD1309** (например U8g2: конструктор `SSD1309_128X64_*`).

При отладке только в Proteus можно временно инициализировать как 1306 и сравнить, что картинка «похожа»; перед установкой на стенд — переключить на 1309.

## Структура репозитория v2

| Путь | Роль |
|------|------|
| `mast_control_v2/` | Скетч Arduino IDE |
| `src_V2/` | Копия для PlatformIO |
| `lib_V2/` | Библиотеки + `proteus_V2/` |

v1 **не трогаем** (`mast_control_v1`, `lib_V1`).

## Порядок работ (предложение)

1. Скетч `mast_control_v2` в IDE + копия логики джойстиков из v1.
2. Proteus v2: Nano, INA219, SSD1306, реле — виртуальная проверка I2C и пинов.
3. Подключить INA219 + экран на одной шине (разные адреса).
4. Экран: заставка, давление, кнопка нуля.
5. Полевая настройка под ИВЭ-50.
