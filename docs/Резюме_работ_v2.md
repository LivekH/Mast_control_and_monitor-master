# Резюме проделанной работы — Mast control v2

Дата актуализации: ноябрь 2025. База: **v1** (джойстики, одна активная ось, реле, ШИМ) без изменения «железной» логики; новое в v2 — **OLED**, **GUI**, **петля 4–20 mA**, **нуль по кнопке**.

## Прошивка

| Компонент | Содержание |
|-----------|------------|
| Скетч | `mast_control_v2/mast_control_v2.ino` |
| Зеркало PIO | `src_V2/mast_control_v2.cpp` |
| Библиотеки | `lib_V2/` — Wire, INA219_WE, U8g2 |
| Сборка Proteus hex | `arduino-cli` → `lib_V2/proteus_V2/firmware/mast_control_v2.ino.hex` |

**Флаг:** `MAST_OLED_PROTEUS` — `1` в симуляции (SSD1306, I2C 100 kHz), `0` на стенде (SSD1309, 400 kHz).

## Давление и INA219

- Петля **4–20 mA** (ИВЭ-50 в разрыве), ток через INA219.
- Пороги: **OPEN** &lt; 3,5 mA, **SHORT** &gt; 20,2 mA, шкала **0…250 bar** от `loop_zero_mA` до 20 mA.
- Нуль по **D12** (удержание **3 с**) или в Proteus — **Virtual Terminal `Z`/`z`**.
- После tare: текущий ток = **0 bar**; ниже нуля на дисплее **не минус**, а **0** (и OPEN при сильном падении).
- Дисплей: усреднение, шаг **2 bar**, зона «малых» значений (`pressure_display_zero_band`).

## OLED GUI

- Давление **000…250 bar**, статусы **PRESSURE SENSOR OPEN/SHORT**, **I2C FAILED**, **ZERO SET** / **TARE FAIL**, **TARE…** при удержании.
- Нижняя строка: разделитель, **3 индикатора осей** (активная — точка + стрелка), **вертикальная шкала ШИМ** с подписями **100** / **0** (шрифт 6×10, центр над/под шкалой).
- Перерисовка по изменению данных (кэш `gui_last_*`).

## Proteus

- Проект: `lib_V2/proteus_V2/`, OLED **SSD1306**, INA219, Nano 16 MHz.
- Защита tare от дребезга D12: повтор только после **отпускания**, cooldown, снятие ZERO SET по таймеру.
- Рекомендация по петле в симуляции: RV **~5,2 kΩ** для плавных шагов тока (см. `proteus_V2/README.md`).

## ШИМ D11 (эксперимент CED252)

- Основная v2: **~976 Hz** на D11 (стандарт Arduino).
- Вариант **`mast_control_v2_PWM244hz`**: **~244 Hz** для сравнения с [Walvoil CED252](https://www.walvoil.com/allegati/catalogo/CED252_US.pdf) (**100–150–220 Hz**), без смены пина.
- Описание: `docs/ШИМ_D11_CED252.md`.

## Следующий шаг
