# Распиновка — Mast control v2 (Arduino Nano, ATmega328P)

Источник истины: `mast_control_v2/mast_control_v2.ino` (блок **ОПРЕДЕЛЕНИЯ ПИНОВ**).

Плата: **Arduino Nano** (ATmega328P). Нумерация — как на silkscreen Nano (**D0…D13**, **A0…A7**).  
Концевики и **D12**: `INPUT_PULLUP`, активный уровень — **GND** (замыкание на массу).

## Шина I2C (общая для INA219 и OLED)

| Arduino | ATmega328 | Назначение |
|---------|-----------|------------|
| **A4** | PC4 / SDA | I2C **SDA** — INA219 (**0x40**), OLED (**0x3C**) |
| **A5** | PC5 / SCL | I2C **SCL** |

Питание и GND модулей — по схеме щита; на шине нужны подтяжки SDA/SCL (обычно на модулях).

## Аналоговые входы

| Arduino | ATmega328 (ADC) | Назначение |
|---------|-----------------|------------|
| **A0** | ADC0 (PC0) | Потенциометр джойстика **ось 1** (секция мачты 1) |
| **A1** | ADC1 (PC1) | Потенциометр джойстика **ось 2** (секция мачты 2) |
| **A2** | ADC2 (PC2) | Потенциометр джойстика **«пальцы»** |
| **A3** | ADC3 (PC3) | Выход на **реле теста клапанов** (код: `test_relay`; штатно отключён) |
| **A7** | ADC7 | **Тест напряжения** на катушках клапанов (`valve_test_pin`; блок теста отключён) |

## Цифровые входы

| Arduino | ATmega328 | Назначение |
|---------|-----------|------------|
| **D8** | PB0 | Концевик **нейтрали ось 1** — разомкнут = нейтраль |
| **D9** | PB1 | Концевик **нейтрали ось 2** |
| **D10** | PB2 | Концевик **нейтрали «пальцы»** |
| **D12** | PB4 | Кнопка **нуль петли 4–20 mA** — удержание **3 с** → `loop_zero_mA` |

## Цифровые выходы (реле)

Логика в прошивке: реле **включено при LOW** (замыкание на массу через драйвер).

| Arduino | ATmega328 | Назначение |
|---------|-----------|------------|
| **D2** | PD2 | Реле **подъём** секции мачты **1** |
| **D3** | PD3 | Реле **спуск** секции мачты **1** |
| **D4** | PD4 | Реле **подъём** секции мачты **2** |
| **D5** | PD5 | Реле **спуск** секции мачты **2** |
| **D6** | PD6 | Реле **закрыть** «пальцы» |
| **D7** | PD7 | Реле **открыть** «пальцы» |

## ШИМ

| Arduino | ATmega328 | Назначение |
|---------|-----------|------------|
| **D11** | PB3 / OC2A | **ШИМ** пропорционального клапана (`output_power`), 0…255, активная ось |

В покое: `digitalWrite(D11, HIGH)` (см. `stopAllMotionOutputs()`).

## Свободные / служебные на Nano

| Arduino | Примечание |
|---------|------------|
| **D0, D1** | UART (USB); не занимать под реле, если нужен Serial |
| **D13** | LED onboard; в v2 не используется |
| **A6** | Только вход (ADC6 на 328P) — в v2 **не задействован** |
