# lib_V1 — зависимости тестовой версии 1

Локальные копии для **PlatformIO** (`lib_dir = lib_V1`) и для **Arduino IDE** (ZIP или «Доп. пути к библиотекам»).

## Библиотеки прошивки v1

| Папка | `#include` | Назначение |
|-------|------------|------------|
| `Wire` | `<Wire.h>` | I2C-шина (INA219 и др.). Копия из пакета **Arduino AVR**; при обычной установке Nano та же `Wire` уже в ядре |
| `INA219_WE` | `<INA219_WE.h>` | Измерение тока, петля 4–20 mA |
| `GyverSegment` | `<GyverSegment.h>` | Индикатор TM1637 |

**`<Arduino.h>`** — только для сборки PlatformIO в `src/mast_control_v1.cpp`, в каталог не входит.

## Прочее

| Папка | Назначение |
|-------|------------|
| `proteus_V1/` | Схема/симуляция Proteus v1 — открывать `Mast_control_and_monitor-master_scheme V3_Dwin.pdsprj` |

Версия **2** — отдельный каталог, например `lib_V2/`.

## Замечание по Wire

Если в IDE уже выбрана плата **Arduino Nano (AVR)** и проект **без** доп. пути на весь `lib_V1`, `#include <Wire.h>` берётся из ядра — дублировать установку **не нужно**.

Доп. путь на `lib_V1` имеет смысл для **офлайн-архива** или если ставите только `INA219_WE` / `GyverSegment` через ZIP.
