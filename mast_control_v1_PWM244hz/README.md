# mast_control_v1_PWM244hz

Экспериментальная прошивка **v1** (TM1637): на выходе **D11** частота ШИМ **~244 Hz** вместо **~976 Hz** у стандартного `analogWrite()`.

## Зачем

По каталогу **Walvoil [CED252](https://www.walvoil.com/allegati/catalogo/CED252_US.pdf)** пропорциональные выходы: **HSD PWM, 100–150–220 Hz**, до **2 A**. Наш Nano на **D11** по умолчанию даёт **~976 Hz**; клапан обычно открывается, но для полевых испытаний сделана отдельная сборка **без переделки платы** (пин **не** переносили на D9, как у части оригинальных схем).

Полное описание: **[`docs/ШИМ_D11_CED252.md`](../docs/ШИМ_D11_CED252.md)**.

## Что в коде

| Функция / место | Назначение |
|-----------------|------------|
| `timer2PwmPrescaler256()` | Делитель Timer2 **/256** → ~244 Hz |
| `analogWriteOutputPowerPwm244(duty)` | ШИМ 0…255 с удержанием частоты (ядро сбрасывает /64) |
| `initOutputPowerPwm244Hz()` | В `setup()` вместо `pinMode(D11)` |
| `applyMotionOutputs()` | Вызовы только через `analogWriteOutputPowerPwm244` |

## Сборка

Arduino IDE → этот `.ino`, плата **Arduino Nano**, библиотеки из **`lib_V1/`** (как v1).

Основная прошивка без смены частоты: `../mast_control_v1/mast_control_v1.ino`.

## Проверка

Осциллограф на **D11** — период ~**4,1 ms** (~244 Hz). Сравнить с основной v1 (~1,02 ms, ~976 Hz).
